# 15 SQL Interview Questions, Solved in SQL Server

If you had **1 week** to prepare for an SQL interview, these are the **15 questions** to practise.
5 Easy, 5 Intermediate, 5 Advanced. Every question comes with the approach, a clean SQL Server solution, the expected output and the common mistake interviewers look for.

## What's inside

| File | What it is |
|---|---|
| `15_SQL_Interview_Questions_Solved.pdf` | All 15 questions with step-by-step approach, solution, expected output and explanation |
| `Practice_Database_15_Questions.sql` | Creates the practice tables in SSMS so you can run every query yourself |

## How to use

1. Download both files.
2. In SSMS, create a database (for example `CREATE DATABASE InterviewPrep;` then `USE InterviewPrep;`).
3. Open `Practice_Database_15_Questions.sql` and press **Execute**.
4. Try each question yourself first. Then compare your result with the expected output in the PDF.

Works on **SQL Server 2017 or later**.

## The 15 questions

| # | Question |
|---|---|
